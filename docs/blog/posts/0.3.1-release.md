# WutherCore 0.3.1 正式发布

WutherCore `v0.3.1` 已作为 Latest Release 发布，提供 Linux、Android、Windows
与 macOS 共 10 个目标的预编译归档。

<!-- more -->

## 发布亮点

- 本地脚本与 GitHub CI 统一支持 Cargo `with_*` 组件标签；
- 提供 `portable`、`portable_boringssl`、`standard` 与完全自定义组件集；
- Linux GNU/musl、Android ARM64/ARMv7、Windows AMD64/ARM64、
  macOS Intel/Apple Silicon 原生构建；
- 每个归档包含实际目标和组件预设清单；
- 发布附带 `SHA256SUMS` 与 GitHub Artifact Attestation；
- 多 Job Actions、Rust target 缓存、依赖缓存、sccache 和原生工具缓存。

[下载 WutherCore 0.3.1](https://github.com/MiChongs/WutherCore/releases/tag/v0.3.1){ .md-button .md-button--primary }

## 校验

```bash
sha256sum -c SHA256SUMS
gh attestation verify <archive.zip> --repo MiChongs/WutherCore
```
